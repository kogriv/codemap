# Гэп — аудит MCP-поверхности codemap

**Дата:** 2026-11-24. **Статус:** исправлено в рабочем дереве, результаты в дизайне. **Версия аудита:** codmap 0.0.47, checkout `707821d`,
MCP SDK 2.0.0, схема графа 0.13, `ANSWER_FORMAT` 12. **Бэклог:** R1-C137…R1-C146.
**Дизайн:** [mcp_surface_contract.md](../docs/design/mcp_surface_contract.md).

## 1. Поверхность и способ проверки

Живой сервер запущен из [проектной конфигурации Codex](../codemap/devkit/templates/codex_region.toml)
по STDIO с `--graph .codemap/graph.json --source-root . --watch`. Граф собран в fast-режиме
по ядру `codemap`, потребителю `tests` и `docs`, режим `full`. Контрольный `stats` вернул
`currency.status: current`, 3 807 узлов и 11 676 рёбер. В списке 29 инструментов.

**Живой MCP** ниже означает прямой вызов из Codex. **Изолированная проба** означает вызов
адаптера MCP через SDK на временном артефакте. **По коду** означает прослеженный путь
в реализации, без подтверждения runtime-сценарием. Полный сьют, глубокую сборку, внешний
семантический адаптер и реальный post-commit в этом аудите не запускали. Замера пропускной
способности нет.

## 2. Находки

### F1 — отрицательный предел и ложные счётчики (P1, R1-C137)

Живой MCP. Для `search(term="extract", limit=2)` контроль дал 2 из 247. Тот же запрос
с `limit=-1` вернул 246 записей при `returned: -1`. `call_contract("codemap.store.load", limit=-1)`
вернул 34 из 35 при том же счётчике. У `impact` на этом символе, с обеими глубинами 1,
вернулись 34 ссылки, `refs_shown: -1` и `flows_shown: -1`. `tests(cap=-1, depth=1)` вернул
20 из 21 и записал `applied: -1`.

Причина — отрицательный аргумент проходит до Python-среза, а счётчики в части операций
считаются через `min`. Это нарушает контракт [R1-C28](limit_truncation_2026-08-28.md).
[Session](../codemap/serve/session.py#L637) ·
[MCP-компактация](../codemap/serve/mcp_server.py#L47).

### F2 — зелёный MCP check без контракта (P1, R1-C138)

Живой MCP. `check()` подтвердил текущий контракт. Вызов `check` с `root`, указывающим на каталог `docs`,
вернул внешний `ok: true`, `result.ok: true`, `contract_empty: true`, `violations: []` и
`graph_currency.status: current`. `current` относится к графу, а `root` выбирает файл правил.
CLI имеет `--require-contract` и `--require-current`, в MCP их нет.

По коду, `check` отдельно вычисляет актуальность без `roots`, `target` и `source_root`,
а внешний конверт использует эти параметры и кэш. При отсутствующем sidecar или смене дерева
между двумя проверками возможны два разных состояния. Случай расхождения на живом сервере
не измерялся. [Операция](../codemap/serve/session.py#L757) ·
[Вердикт](../codemap/serve/check.py#L96) · [CLI](../codemap/cli.py#L1035).

### F3 — source смешивает координаты графа и текущий файл (P1, R1-C139)

Живой контроль. Для `Session._handle` текущий сервер отдал строки 430–472 и 2 542 символа
кода. Для модуля `codemap.cli` с известным файлом и без номеров строк ответ назвал его
`overlay node`, хотя это обычный модуль.

По коду, для символа с координатами `source` читает текущий файл и режет его по номерам
строк из графа. После вставки перед символом эти координаты могут указывать на другой текст.
Сверка актуальности происходит в конверте уже после чтения, а по умолчанию её результат
кэшируется 10 секунд. Сдвиг строк на живом дереве не воспроизводили.
[Чтение source](../codemap/serve/session.py#L837) · [Кэш](../codemap/serve/session.py#L540) ·
[Заполнение координат](../codemap/extract/griffe_extractor.py#L829).

### F4 — post-commit публикует рецепт для промежуточного пути (P1, R1-C140)

По коду. В обеих ветках хук вызывает `build -o <graph_next>`, затем переносит граф и
sidecar под конечные имена. `build` записывает фактический `argv`, а `refresh` проверяет,
что его эффективный `-o` совпадает с запрошенным путём. У успешно опубликованного таким
способом рецепта пути расходятся. Эта цепочка затрагивает инструкцию devkit для
агента при `currency: behind`. Сам хук в ходе аудита не запускали.
[Хук](../codemap/devkit/templates/post-commit.sh#L20) · [Запись рецепта](../codemap/cli.py#L225) ·
[Проверка refresh](../codemap/cli.py#L911).

### F5 — reload считает размер и публикует граф до индексов (P2, R1-C141)

Изолированная проба. На диске заменили граф с одним символом `sample.before` на граф
с одним символом `sample.after`, в обоих ноль рёбер. `reload` вернул `reloaded: true`,
`changed: false`, затем `search` нашёл `sample.after`. Watcher использует тот же флаг для
строки «identical».

По коду, `self.graph` присваивается раньше `Query(graph)`. Исключение при построении
индексов оставит новый граф со старым индексом и старым кэшем. Этот сбой не инъецировали.
[Замена снимка](../codemap/serve/session.py#L570) · [Watcher](../codemap/cli.py#L1295).

### F6 — выходной контракт и статусы ошибок расходятся (P2, R1-C142)

Живой список инструментов показал 29 `inputSchema`, ноль `outputSchema` и ноль
`annotations`. Изолированный вызов `search` дал JSON в текстовом блоке без
`structuredContent`. Живой `callers` с неверным `min_confidence` дал MCP
`isError: false`, внутреннее `ok: false` без `answer_format` и `currency`.
`source` неизвестного символа вернул внешний `ok: true`, `resolved.found: false`
и вложенный `result.error`. `pack` с ненайденным seed вернул внешний `ok: true`
и вложенный отказ. `callers` для неизвестного символа вернул пустой список и
`resolved.found: false`. Эти состояния различаются по смыслу, но клиенту
приходится знать правила конкретного инструмента.
[Адаптер](../codemap/serve/mcp_server.py#L103) · [Конверт](../codemap/serve/session.py#L396) ·
[Отказ pack](../codemap/serve/pack.py#L110).

### F7 — валидация, разрешение имён и подсказки агенту (P2, R1-C143)

Живой MCP. `search(term="extract", kind="functon", limit=2)` ответил нулём вместо ошибки
параметра. `locate(file="codemap/cli.py")` вернул внутренний `TypeError` вместо подсказки
о `line` либо `start/end`. `resolve` неизвестного имени вернул `result: null` без
`resolved`, хотя `callers` пометил тот же ввод как ненайденный. `impact("main")` вернул
две цели без метки множественного разрешения. Веер по короткому имени предусмотрен
реализацией и должен сохраниться.

По коду и документации, описание MCP `tests` обещает бесплатный переход через
помощника в тестовом модуле. Бесплатен переход к контейнеру для вложенной функции,
а помощник на уровне модуля добавляет шаг. [Инструменты](../codemap/serve/mcp_server.py#L133) ·
[Разрешение impact](../codemap/query.py#L408) · [Обход тестов](../codemap/query.py#L1723) ·
[Документация тестов](../docs/test-mapping.md).

### F8 — скрытое усечение и стоимость компактного impact (P2, R1-C144)

По коду, `architecture.hotspots` обрезает классы, функции и узлы вызовов до 15 элементов
на список, без исходных счётчиков. Живой `impact(full=true, limit=1)` вернул полный ответ
с Markdown без `limit`. Полная выдача задумана как отключение лимита, а общая инструкция
обещает блок для любого инструмента, который принимает `limit`.

Компактный `impact` сначала вычисляет структурированный ответ, затем вызывает рендер,
который заново обходит граф. MCP удаляет Markdown после вычислений. Сессия обрабатывает
операции и reload под одной блокировкой. Влияние на задержку на больших графах не измерялось.
[Hotspots](../codemap/query.py#L1518) · [Impact](../codemap/serve/session.py#L613) ·
[Повторный обход](../codemap/serve/impact.py#L84) · [Компактация](../codemap/serve/mcp_server.py#L47).

### F9 — lower bound для результата с эвристическими кандидатами (P2, R1-C145)

Живой контроль показал `epistemic: partial` у `callers` и `flows`. По коду, один
текст про «lower bound» применяется и при наличии эвристических рёбер. Неразрешённые
вызовы дают пропуски, а веер реестра или протокола может добавить лишних кандидатов.
В `tests` достижимость по графу служит подсказкой для выбора тестов, а факт исполнения
устанавливает runtime-проверка. На данном fast-графе все классифицированные рёбра имели
грейд `exact`, сценарий с эвристикой в этой сессии не измерялся.
[Метки](../codemap/serve/session.py#L64) · [Точность](../docs/accuracy.md).

### F10 — source-root ограничивает одну операцию (граница доверия, R1-C146)

По коду. `source` проверяет разрешённый путь относительно `source_root`, а загрузчик графа
отвергает абсолютный `node.file` и компоненты `..`. `diff(base)` читает файл по пути,
который задаёт клиент. `check(root)` читает `codemap.toml` из заданного каталога.
Включённый `semantic_search` может вызвать внешний адаптер в рабочем каталоге проекта.
На текущем сервере живая проба семантического поиска дала `resolver: null`.

Это инвентаризация возможностей локального STDIO. Общий контур изоляции для всех операций
отсутствует. Проверок чтения чувствительных файлов, запуска адаптера и атак на границы
процесса в этом аудите не было. [Пути diff/check](../codemap/serve/session.py#L743) ·
[Ограничение source](../codemap/model.py#L428) · [Адаптер](../codemap/integrations/cocoindex.py#L45).

## 3. Связанные решения

- R1-C28 задаёт учёт усечения, R1-C44 разделяет ненайденное и пустое.
- R1-C70, R1-C85 и R1-C127 задают сверку актуальности и строгий CLI-гейт.
- R1-C122 защищает обработку запроса от перемешивания с reload. F5 касается отказа внутри замены.
- R1-C124, R1-C125 и R1-C134 сохраняют атомарную публикацию и ограничивают повтор рецепта.
  F4 касается рецепта, который генерирует сам devkit.
