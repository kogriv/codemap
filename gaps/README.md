# codemap — гэпы и аналитика покрытия

**Последнее обновление:** 2026-07-26

Документы этого раздела фиксируют **ограничения, расхождения дизайн↔реализация и пробелы**
инструмента `codemap/` — статического анализатора кода, который строит queryable граф пакета.

Раздел живёт **внутри подпроекта** `codemap/gaps/` рядом с `DESIGN.md` и `BACKLOG.md`.
`codemap` не входит в wheel `bquant`; контекст в репозитории — `../README.md`,
`devref/architecture/package_roadmap_2026-07.md` (стадия P1).
