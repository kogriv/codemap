# codemap — гэпы и аналитика покрытия

**Последнее обновление:** 2026-08-24

Документы этого раздела фиксируют **ограничения, расхождения дизайн↔реализация и пробелы**
инструмента `codemap/` — статического анализатора кода, который строит queryable граф пакета.

Раздел живёт рядом с `DESIGN.md` и `BACKLOG.md` в корне репо. codemap выделен в самостоятельный
репо-продукт из монорепо `bquant`, где инкубировался; `bquant` остаётся подопытной мишенью обкатки
(`codemap build ../bquant` — как сторонний тул на внешнем пакете).

## Реестр осей обкатки

**[dogfood_axes.md](dogfood_axes.md)** — единый **живой реестр осей** (под каким углом проверяем
инструмент): что закрыто (A1–A8 → findings F1–F13), что открыто (A9–A12 задачи, B1 soundness, B2
робастность), приоритет и стоп-критерий. Начинать новую обкатку — отсюда.
