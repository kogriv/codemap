# Гэп: несуществующий корень `--consumer` / `--docs` принимается молча

**Дата:** 2026-11-05. **Источник:** воспроизведение R1-C80 на bquant
([kogriv/codemap#25](https://github.com/kogriv/codemap/issues/25)). **Статус:** ✅ закрыто 2026-11-05 (0.0.29);
дизайн — [`docs/design/missing_roots.md`](../docs/design/missing_roots.md), бэклог R1-C84.

## 1. Что показали

Фикстура из двух файлов (`pkg/core.py`, `tests/test_a.py`), `main` bed0daf:

```
codemap build pkg --consumer tests,examples --mode full -o g.json   → exit 0, граф без тестов
codemap build pkg --consumer nope            -o g.json              → exit 0
codemap build pkg --docs nope                -o g.json              → exit 0
codemap build pkg --consumer pkg/core.py     -o g.json              → exit 0 (файл, а не каталог)
codemap scope pkg --consumer nope --no-git                          → exit 0
```

Ни одна команда не назвала корень, который не прочитан. Единственная строка в stderr — предупреждение о пустом
графе импортов, и оно про другое. Первая форма — та, в которой корни передали на bquant: список через запятую
одной строкой. `tests` потом отвечает «no test functions in this graph», и причину оттуда не видно.

## 2. Почему так

`_scan_consumer_root` и `_scan_doc_root` (`extract/roots.py`) начинаются с `if not root_dir.is_dir(): return`.
Проверка стоит там, чтобы сканер не упал, но она же глотает ошибку пользователя. Провенанс графа при этом
записывает корень в `roots.consumers` как прочитанный, хотя из него не взято ничего.

## 3. Чем это опасно

Граф репозитория, в котором нет корня, отвечает на `tests`, `impact` и `covers` так, будто потребителей нет.
`impact` скажет «0 внешних вызывающих», `tests` скажет «тестов нет». Пустота здесь означает «не прочитано», а
читается как «проверено, ничего нет». Это та же семья, что R1-C21 (пустой граф импортов) и R1-C69 (контракт с
опечаткой): ответ, который не называет, чего не видел. Провенанс при этом заявляет корень прочитанным.

## 4. Что не является причиной

- **Не режим.** `thin` и `full` ведут себя одинаково.
- **Не `scope`.** Манифест считается от тех же путей. Он тоже молчит, но не он их теряет.
