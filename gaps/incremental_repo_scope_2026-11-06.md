# Гэп: инкрементальная сборка не работает для графа репозитория и для пакета не в корне git

**Дата:** 2026-11-06. **Источник:** bquant (вопрос, 2026-11-05, [kogriv/codemap#25](https://github.com/kogriv/codemap/issues/25));
второй дефект найден при подготовке дизайна. **Статус:** ✅ закрыто 2026-11-06 (0.0.34); дизайн —
[`docs/design/incremental_repo_scope.md`](../docs/design/incremental_repo_scope.md), бэклог R1-C86.

## 1. Что показали

**(a) Граф репозитория всегда собирается полностью.** `build --incremental` с `--consumer`/`--docs` печатает
«[note] --incremental was not applied … repo-scoped build, which is always full». `watch` с консьюмерами (так
работают MCP-скрипты bquant и bquearch) пересобирает целиком на каждую правку. Замер на bquant `cf039ef`:
ядро 9.7 с, граф репозитория 15.7 с на fast; ~110 с на deep, из них сканы консьюмеров и документации ~6 с.
Ответ после правки на deep отстаёт на две минуты.

**(b) Пакет не в корне git: инкрементальная сборка не видит правок.** Git-репозиторий, пакет в
`research/shared/`, `codemap build shared -o g.json`, затем правка `shared/m.py` и
`codemap build shared --incremental -o g.json`:

```
[incremental] unchanged: 0 module(s) recomputed
```

Граф остаётся старым. Манифест scope в git-режиме отсчитывает пути от корня репозитория
(`research/shared/m.py`), а `incremental._path_to_module` требует, чтобы путь начинался с имени пакета
(`shared/…`). Ни один путь не сопоставляется, и правка считается нулевой. `watch` без консьюмеров идёт через
этот путь, поэтому для такого пакета он молча держит устаревший граф и пишет, что пересобрал.

## 2. Почему так

(a) — решение R1-C44: инкрементальный путь писался для одного пакета, а для графа репозитория стоит граница.
(b) — допущение R1-C9: пакет лежит в корне scope. Оно верно для bquant и codemap и неверно для `src/`-раскладки
и для подкаталога (`research/shared`). Тесты R1-C9 строят фикстуры без git (режим fs, корень = родитель пакета),
поэтому git-случай не проверялся никогда.

## 3. Чем это опасно

(a) — цена: две минуты молчаливого отставания после каждой правки. С 0.0.33 оно хотя бы называется (`currency`).
(b) — ложь: граф устарел, а сборка сообщает «unchanged». Та же семья, что #3 и R1-C70: устаревший ответ с меткой
«актуален».
